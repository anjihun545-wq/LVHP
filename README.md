# LocalVision v0.3.22 — 탭별 팝업 24시간 숨김 분리

- `24시간 동안 열지 않기` 상태를 사장님 / 광고주 / 기관 탭별로 각각 저장하도록 수정
- 사장님 탭에서 24시간 숨김을 눌러도 광고주·기관 팝업은 정상 노출
- 광고주 탭에서 숨김을 눌러도 사장님·기관 팝업 상태에는 영향 없음
- 기관 탭도 동일하게 독립 동작
- X(닫기) 역시 현재 탭의 팝업만 현재 페이지에서 닫도록 분리
- 팝업 이미지를 눌러 문의폼을 연 경우에도 현재 탭 팝업만 닫힘
- v0.3.20~v0.3.21에서 사용하던 전체 탭 공통 숨김 키는 자동 정리
- 기존 문의 폼 / Vercel API / Apps Script / 이미지 가독성 수정 유지

# LocalVision v0.3.21 — Public Space Visibility Fix

- 공공정보 생활동선 섹션의 실제 운영 이미지 가독성 개선

- 데스크톱은 더 큰 카드와 느린 자동 마퀴 유지
- 기존 문의 팝업 / Vercel API / Apps Script 연결 구조 유지

# LocalVision v0.3.20 — Image Popup Production

## 이번 버전
- 사장님 / 광고주 / 기관 탭별 정사각형 프로모션 이미지 자동 전환
- PC: 메인 520px 캔버스 왼쪽 여백에 팝업 노출
- 모바일: 첫 Hero 화면 위 중앙 팝업 노출
- 팝업 이미지 클릭 시 현재 탭에 맞는 문의 폼 즉시 오픈
- X 버튼: 현재 페이지에서 팝업 닫기 (새로고침 시 다시 노출 가능)
- `24시간 동안 열지 않기`: localStorage 기준 24시간 동안 재노출 방지
- 문의 모달이 열려 있는 동안 팝업 자동 숨김
- 기존 Vercel `/api/inquiry` → Apps Script → Google Sheet / 메일 구조 유지
- Safari/Chrome 메인 타이틀 렌더링 안정화 유지
